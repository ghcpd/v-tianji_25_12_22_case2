**Clarifying questions**:
- Are the `handleResize` and `handleClick` functions intended for future features, or can they be removed if they're just logging placeholders?
- Is there a specific reason these global listeners are needed (e.g., for analytics), or are they remnants of development?
- What browser support is required (e.g., does it need to work in older browsers where event listener cleanup is more critical)?

**High-level approach**:
1. Modify the `useEffect` in App.tsx to return a cleanup function that removes the event listeners.
2. If the handlers are not needed, remove them entirely to simplify the code.
3. Test the app to ensure no functionality breaks (e.g., add/remove todos still work).
4. If keeping the listeners, consider adding conditions to avoid unnecessary re-additions on re-renders.
